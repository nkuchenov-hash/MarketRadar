# MarketRadar Android 0.2 — поиск и подключение магазинов

Это автономное Android-приложение для входа на сайты Ozon, Wildberries и Яндекс Маркета через встроенный Android WebView и пробного поиска точных моделей в **локальных WebView-сессиях**.

## Сборка
- Android SDK 35, Java 17, Gradle 8.9, Android Gradle Plugin 8.7.3
- `gradle -p android testDebugUnitTest assembleRelease`
- CI проверяет сборку и модульные тесты и публикует подписанный APK 0.2.
- **0.2 — отдельное приложение** с package ID `com.marketradar.mobile.next`, чтобы установка не трогала 0.1 (`com.marketradar.mobile`). Обе версии могут стоять одновременно. **Авторизации не переносятся**: при первом запуске 0.2 нужно войти в каждый маркетплейс заново, но данные в 0.1 остаются.
- Исходный приватный ключ 0.1 создан одноразово и утрачен. Android не позволяет безопасно обновить 0.1 другим ключом без переустановки.
- Для версии 0.2 CI создаёт **один постоянный ключ** и сохраняет резервную копию в **непубличном draft release** `marketradar-private-v2-signing`. На следующих сборках ключ восстанавливается из этого закрытого черновика. В публичный релиз ключ и пароль не попадают.
- Доступ на запись в репозиторий должен быть ограничен. Черновик с ключом **нельзя публиковать**. Для промышленного выпуска рекомендуется мигрировать резервную копию в GitHub Actions Secrets/защищённый секретный менеджер.
- CI сравнивает SHA-256 сертификат новой сборки с резервной копией и с уже опубликованным APK 0.2 и отказывает в публикации при несовпадении.
- **Не удаляйте 0.1** до завершения проверки 0.2 и подключения новых сессий. Удаление 0.1 сбросит только её данные.
## Сценарий
1. Установить APK Android 8.0+.
2. Открыть `Ozon`, `Wildberries` или `Яндекс Маркет` из раздела «Мои маркетплейсы».
3. На официальном сайте пройти обычную авторизацию. MarketRadar не просит ввести пароль или SMS-код в собственную форму.
4. Нажать «Готово». Приложение сохраняет cookies штатными средствами Android WebView; статус «сессия сохранена» **не удостоверяет**, что магазин действительно авторизовал пользователя.
5. На главном экране ввести точную модель, выбрать магазины и глубину поиска, затем нажать «Найти предложения». Сканирование идёт внутри приложения без выноса страниц на экран. Результаты являются **предварительными**, цены с карты/доставкой не проверяются в корзине.
6. При блокировке или капче приложение показывает отсутствие доступной карточки либо ограничение, а не подставляет цену.

## Ограничения
- WebView обладает собственными cookies, не использует Chrome/Яндекс Браузер или установленные приложения маркетплейсов.
- Ozon, Wildberries и Яндекс Маркет могут блокировать вход, автоматические переходы и JavaScript на страницах WebView. Доступ на реальных устройствах/с учётными записями **не подтверждён**. Не пытайтесь обходить капчу или антибот-проверки.
- Поиск выполняется **внутри открытого приложения**. Пока он работает, страницы скрыты за интерфейсом, но при сворачивании Android может приостановить WebView. Это не полноценный серверный фоновый агент.
- Из-за ограничений поиска (до восьми ссылок на магазин, без бесконечной прокрутки) самая дешёвая цена на рынке **не гарантируется**.
- Результаты не берут минимальную сумму из любых цен на странице. Цена появляется только при наличии метаданных Product/Offer либо product price meta для точного названия. Другие суммы (включая стоимость аксессуаров и рассрочку) игнорируются.
- Структурированные цены по-прежнему не подтверждают тип скидки, карту, доставку или фактическую сумму заказа. В сводке это обозначено, а обычная цена не выдумывается.
- Cookies сохраняются только в Android WebView на устройстве, не отправляются в MarketRadar или ИИ-провайдер. Для удаления используйте кнопку «Сбросить все входы».
- Нет синхронизации аккаунтов с облачным сайтом MarketRadar и нет отдельного API-ключа.
- Сборка, тесты на JVM и проверка подписи не заменяют испытаний на реальном Android-устройстве.
