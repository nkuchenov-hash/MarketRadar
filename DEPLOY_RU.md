# MarketRadar — облачная сборка 1.8 (staging, мобильный поиск)

## Что работает в коде
FastAPI веб-сервис, регистрация/вход, история товаров, необязательное расширение для персональных цен на ПК, фоновая очередь облачного поиска без расширения на Android, ИИ через серверный API без ввода пользовательских API-ключей, пробный лимит, подготовленная Stripe-интеграция.

## Развёртывание на Render
1. Подключить Render и GitHub, создать ОТДЕЛЬНЫЙ репозиторий MarketRadar (не использовать другие проекты).
2. Отправить содержимое этой папки в репозиторий. Render Blueprint прочитает `render.yaml` и создаст веб-сервис с платным persistent disk 1 GB.
3. В Render указать серверный `OPENAI_API_KEY` в секрете; ключ браузерным пользователям не передаётся. Для оплаты заполнить переменные Stripe и проверить webhook в тестовом режиме.
4. Render выдаст HTTPS-домен .onrender.com. В конфигурации `APP_ORIGIN` подставляется `RENDER_EXTERNAL_URL`. При подключении собственного домена обновить `APP_ORIGIN` на него.
5. На Android пользователь открывает опубликованный адрес Render, входит в MarketRadar и выбирает «Облачный поиск». Расширение и API-ключ ему не нужны. Однако серверный браузер использует только публичные цены и не переносит авторизации из приложений Android.
6. На ПК для персональных цен пользователь может дополнительно загрузить расширение с сайта по адресу `/download/extension`, включает в Яндекс Браузере/Chrome, вводит HTTPS-адрес сайта и код из личного кабинета.

## Ограничения до публичного запуска
Обязательны живые тесты поиска на WB/Ozon/Яндекс Маркете через обычный браузер, отдельное UX-тестирование, публикация расширения в магазине, политика приватности, подтверждение email/сброс пароля, безопасность, нагрузочные испытания, тестовые платежи. SQLite + persistent disk — только ограниченная бета на одном экземпляре (Render не поддерживает масштабирование экземпляров с диском); для масштабирования понадобятся PostgreSQL + внешняя очередь.

GitHub Pages показывает только статический тест расширения; мобильный поиск доступен лишь после фактического развёртывания облачного сервера. Перед запуском убедитесь, что /health сообщает cloud_available=true. Антибот-защита магазинов может блокировать облачный Chromium, и это нельзя скрывать или объявлять результатом с минимальной ценой.

Это *staging* сборка, НЕ сертифицированный коммерческий релиз. Администратор оплачивает API. ChatGPT Plus пользователя не используется как backend биллинг.
