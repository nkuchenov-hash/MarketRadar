# MarketRadar — готовый сервер для РФ

Это подготовленный пакет развёртывания, а не свидетельство аренды и запуска
постоянного сервера. Сейчас платежей и аккаунтов пользователей в репозитории нет.

## Что нужно выбрать у провайдера

Подойдёт **любой российский VPS** с Ubuntu 24.04 и Docker Compose V2:
Beget (готовый образ Docker), Timeweb Cloud VPS и аналоги.

Начальная конфигурация для **одного тестировщика**:
- 2 vCPU, 4 ГБ RAM, 25–40 ГБ SSD/NVMe;
- публичный IPv4;
- вход в веб-терминал или SSH;
- открыты входящие TCP-порты **80 и 443** для HTTPS.
- отдельные SSL-сертификаты и покупка домена не нужны для теста.

Оплата провайдера и выбор тарифа — отдельное действие владельца.
Цены и условия смотреть перед подтверждением тарифа. Скрипт установки
ничего не покупает и никуда не отправляет платёжные сведения.

## Самый простой способ запуска

В панели VPS выбрать **Ubuntu + Docker**. После создания открыть терминал
VPS и вставить **одну команду**:

~~~bash
curl -fsSL https://raw.githubusercontent.com/nkuchenov-hash/MarketRadar/main/deploy/bootstrap.sh | sudo bash
~~~

Скрипт самостоятельно:
1. проверит Docker/Compose и обнаружит публичный IPv4;
2. выдаст временный бесплатный домен вида \`<IP-с-дефисами>.sslip.io\`;
3. скачает код из GitHub в \`/opt/marketradar\`;
4. создаст приватный криптографический ключ и защитит его правами 0600;
5. соберёт Chromium и запустит сервер в контейнере;
6. включит HTTPS и автоматическое продление сертификатов через Caddy;
7. проверит локальный сервер и доступность публичного HTTPS;
8. включит ежедневные локальные копии базы (если VPS использует systemd),
   с хранением последних 14 дней;
9. покажет адрес + код для Android.

**Ни пароль маркетплейса, ни данные оплаты никуда вводить не нужно.**
Интернет-магазины по-прежнему могут отклонять запросы с IP VPS — это
выявляется отдельным реальным тестом поиска.

\`sslip.io\` — внешний бесплатный DNS для тестового адреса. Он зависит от
стороннего сервиса и не предназначен как постоянный брендовый домен.
Позднее можно использовать любой собственный домен без переименования приложения.

## Android

В установленном APK открой **Настройки → Облачный браузер**.

- Адрес: то, что выведет установщик (\`https://...\`).
- Код доступа: длинная строка из вывода установщика.
- Сохранить настройки, затем открыть поиск и проверить контрольный товар.

Сервис не копирует cookie и пароли магазинов с телефона. Без адреса облачного
сервера приложение продолжает использовать локальный механизм.

## Контрольные проверки на VPS

Без реального поиска:

~~~bash
sudo bash /opt/marketradar/deploy/verify.sh
~~~

С реальным публичным поиском Яндекс Маркета:

~~~bash
sudo bash /opt/marketradar/deploy/verify.sh --live
~~~

Скрипт сообщает состояние магазина и число реально полученных карточек.

Копии базы лежат на том же VPS; от потери всего сервера защищает только
дополнительный внешний бэкап или снапшот провайдера.
**Положительный HTTP-ответ сервера не означает, что маркетплейс предоставил
товарную выдачу:** проверять надо количество и цену найденных товаров.

Обновить из GitHub с резервной копией и откатом при нездоровом сервере:

~~~bash
sudo bash /opt/marketradar/deploy/update.sh
~~~

Создать резервную копию базы:

~~~bash
sudo bash /opt/marketradar/deploy/backup.sh
~~~

Автоматическое обновление исходников специально не включается до завершения
живой приёмки, чтобы очередной экспериментальный коммит не нарушил работающий поиск.

## Границы ответственности

- HTTPS настроен автоматически только после того, как порты 80/443 открыты
  и домен разрешается в публичный адрес VPS.
- API с дорогими браузерными поисками защищён ключом и ограничителями запросов.
  Наружу доступны только \`/health\` и \`/api/mobile/browser/*\`.
- SQLite хранится в постоянном томе Docker; копии делает \`backup.sh\`.
- Все ключи находятся только в \`/opt/marketradar/.env.production\` на VPS.
  **Не отправляйте этот файл в чат или GitHub.**
- Реальные цены, сроки и охват выдачи должны быть проверены на запущенном VPS;
  успех CI и Docker-сборки не подтверждает работу всех трёх маркетплейсов.

## Можно ли сменить название приложения или провайдера?

Да. Домен, VPS, Android-приложение и бренд независимы. Изменение названия
MarketRadar не требует смены провайдера, а перенос VPS не требует смены бренда.
